# Wellspring calendar

A React and TypeScript operations calendar for a bottling company. The sidebar switches between the Calendar and Events pages using React state; no router is required. Search and category filters apply to both pages, and events created on either page are available on both.

The initial events are example data. Changes are kept in memory and reset when the page is refreshed.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` for a production build and `npm run lint` to check the code.
